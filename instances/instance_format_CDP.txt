Capacitated Diversity Problem Instances format
------------------------------------------------

There is 1 folder in the Const-CDPlib.zip file:
* Const-CDPlib - 100 GD instances

The format of the file is:

The first line has:
*n: Integer indicating the total number of elements 

The following [n*(n-1)/2] lines contain the distance between elements with the format:
elementA elementB distance

Each of the following n lines has the following fields separated with spaces: 

* i: Integer identifying the element
* c: Float indicating the storage capacity of element i

The last line contains the following fields separated with spaces: 
* B: the minimum capacity
