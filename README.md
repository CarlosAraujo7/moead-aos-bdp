# MOEA/D with an operator pool for bi-objective dispersion problems

Code, analysis scripts and derived results for the article *"Objective scaling, operator pools and adaptive selection in MOEA/D for bi-objective dispersion problems"* (working title; submission to the *European Journal of Operational Research* in preparation).

The study compares a MOEA/D with a pool of eight neighbourhood operators — with uniform selection and with adaptive operator selection (UCB1, Thompson sampling, a Gaussian sampler, the published dynamic Thompson sampling, FRRMAB) — against NSGA-II, SMS-EMOA, GRASP, variable neighbourhood search and tabu search on three bi-objective (MaxSum + MaxMin) problems:

* **MDP** — maximum diversity problem (fixed cardinality `m`);
* **CDP** — capacitated dispersion problem (minimum aggregate capacity, free cardinality);
* **GDP** — generalised dispersion problem (capacity and a cost budget).

It covers objective scaling inside the Tchebycheff function, operator-pool ablations, a mechanism study of when adaptive selection pays off, a MaxMin anchoring step, baselines tuned with the same protocol as the proposed method at equal wall-clock time, and the size of the selected set as a hidden dimension of the constrained problems.

## Where things are

| Path | Content |
|---|---|
| `src/` | algorithms (`moead_aos.py`, `mab.py`, `operators.py`, `nsga2.py`, `smsemoa.py`, `grasp_mo.py`, `vns.py`, `bo_trajectory.py`), problems (`problem.py`, `capacitated_problem.py`), anchoring (`anchor.py`, `sbts_anchor.py`), indicators and reference fronts (`metrics.py`, `reference_sets.py`) |
| `run_*.py`, `run_queue*.py` | experiment runners (one JSON file per instance, method and replicate; resumable) |
| `analyze_*.py`, `make_*.py`, `regen_all.py` | statistics, tables, figures and manuscript generation |
| `regression_check.py` | re-executes stored runs from their seeds and checks the fronts bit for bit |
| `results/analysis/`, `results/reference_fronts/frozen_2026-10-06/` | derived results and the frozen reference fronts used in the article |
| `instances/` | instance catalogues only (the instance files come from public sources: see `README_REPLICATION.md`) |
| `latex/` | LaTeX source of the article (EJOR `elsarticle` template), generated by `make_latex.py` |
| `Claude outputs/` | manuscript sources, generated tables and figures |

The run files (about 100 000 JSON files, 84 MB) are deposited separately; `README_REPLICATION.md` lists the commands that regenerate every table and figure and `DATA_PACKAGE_MANIFEST.md` the content of the data deposit.

## Installation

```bash
pip install -r requirements.txt     # Python 3.12
python regression_check.py          # about 2 minutes; expects: 70 identical, 0 different
```
